# 栖木之家 · 概念与色彩

设计主题「浅木、柔光、留白」。连续浅橡木地面串联客餐厅、走廊、卧室和书房；米白墙面承接日光，厨房和卫浴换为浅灰石色。柜体减少外露把手及复杂凹槽，清洁面保持完整。

可见色彩方向：米白/浅石色约60%，浅木约30%，织物与暖灰金属约10%，为概念控制比例，不是工程量。

1. 公共区以低矮电视柜和可移动家具保持开放，餐边柜采用浅木面与暖灰石材感。
2. 两卧采用同一材料家族，通过织物色区分；书房用封闭柜下部与开放书格组合，控制视觉杂乱。
3. 厨房台面M07、柜面M06、背板M10；湿区M03/M10。干湿材料在门口平接，构造厚度需实际选品后确认。
4. 灯光以3000K公共/休息区、3500K厨房和工作区作为选型意向，任务灯独立控制。

不采用通体亮面、复杂叠级顶、满墙格栅与不可维护的隐藏设备。儿童学习位优先尺寸和照明，饰品后置。

材料编号及具体规格见06-finishes.md和材料清单；模型只表达色彩和体量，实际触感、色差及性能通过送样确认。
