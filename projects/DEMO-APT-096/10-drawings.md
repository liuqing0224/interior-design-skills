# 图纸目录与生成关系

最终设计v1.1；坐标原点为西南内墙角，X向东、Y向北，单位mm。所有SVG、DXF及PDF图面共享`drawing_lib.py`和`model/project.json`，不另建一套图面尺寸。

| 图号 | 图名 | 内容 |
|---|---|---|
| ID-01 | 家具与空间平面 | 家具/定制编号、门窗、房间及主体尺寸 |
| ID-02 | 地材与铺装意向 | 地材编号、板缝/砖缝及净分区 |
| ID-03 | 灯位与控制分组 | 灯具编号与控制组，虚线表示组别关系 |
| ID-04 | 设备与机电条件 | 设备、条件点位及距完成地面标高 |
| ID-05 | 定位与开口尺寸 | 总轮廓、分区尺寸和门窗洞口编号 |
| ID-06 | 定制立剖与收口 | 衣柜立剖、厨房立面及干湿地面接口意向 |

`drawings/ID-01.svg`至`ID-06.svg`为独立矢量图。`drawings/interior-set.dxf`将6组图按3列×2行排布，模型空间1:1，INSUNITS=4（毫米）；同名`interior-set.py`保留`gen_dxf()`生成入口。

`documents/栖木之家_方案与深化图集.pdf`共12页A3横版：前6页讲解方案、材料、预算和技能流程，后6页为图纸。后6页平面图按A3原幅1:50编排；节点注明示意。PDF嵌入中文字体，图面经PNG逐页查看。

文件检查覆盖DXF读取/audit、实体与图层、闭合矩形及主要尺寸、6张SVG解析、PDF页数/中文文本/图号与预算。具体证据见`state/artifact-check.json`与根目录`VALIDATION.md`。灯位图未进行照度仿真；机电条件不包含回路保护、管径和坡度计算，保持设计深化阶段的图名与范围。
