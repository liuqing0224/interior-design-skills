# 折庭 · 84㎡ L形跨户型测试

这是用于检查15 Skills复用能力的设计设定。轮廓、尺寸、材料和单价均为测试输入。重点执行总控、平面、图纸、预算及校审5个阶段，保留原96㎡住宅示范。

## 当前结果

- 轮廓84㎡，包围框94.5㎡，净分区80.5128㎡。6个矩形净分区组成L形布局。
- 17个家具/柜体/设备体量，6种材料、10个灯位、6个控制组、3项设备、4处条件点位。
- 6张SVG、6组DXF、8页A3图集、8份CSV及可重算预算工作簿。
- 预算26行，21行使用模型计量规则。当前含预备费总额182055.87元。

## 设计变更

`CAB-A`衣柜由2200×600×2200调整为2600×600×2450mm，正面方向为Y轴。净分区及其他家具保持同一数据条件。平面、立剖、柜体清单与费用已分别读取核验。

| 柜体投影面积（㎡） | 4.84 | 6.37 |
| 该柜体估算（元） | 5082.00 | 6688.50 |
