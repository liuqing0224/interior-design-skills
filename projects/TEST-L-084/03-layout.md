# 平面与轮廓

内轮廓以6个正交顶点表达，原点偏移至(1000,2000)，包围框10500×9000mm。北侧东端凹口3000×3500mm，面积10.5㎡。实际面积为94.5-10.5=84㎡。

LOUNGE与COOK位于南侧，PASS形成1080mm横厅通道；北侧依次为SLEEP、WORK、WASH。内部隔墙120mm。房间净分区80.5128㎡与内隔墙共同覆盖真实轮廓，不覆盖凹口。

餐桌与餐边柜净距550mm，本测试目标500mm；床侧与衣柜净距880mm，本测试目标800mm。均为项目设计目标。柜体CAB-A沿Y轴作正面，调整长度后仍位于SLEEP边界内，未与床及通道碰撞。

可选的淋浴对象不设置，检查工具不得补画原示范中的淋浴、灶具或水槽。厨房仅绘制明确的SINK-A设备轮廓。

证据：`state/model-check.json`、`schedules/rooms.csv`与`drawings/ID-01.svg`。
