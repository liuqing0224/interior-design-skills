# 材料与收口

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

平面、概念材料方向、湿区和基层条件。

## 执行

1. 区分净面积、扣减、损耗和采购量，按真实几何计算，注明柜下是否满铺。
2. 按房间关联地面、墙面、顶面与踢脚，检查材料编号可解析。
3. 定义门口、干湿区、异材和柜体端部的收口原则；将产品厚度纳入标高协调。
4. 将耐磨、防滑、环保、燃烧及湿区适用性落实到待核对的具体产品资料或已核验依据。
5. 列出样板、色差、批次与替代材料确认流程，不编造品牌和检测报告。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

06-finishes.md、材料清单、铺装图、节点说明、送样表。

表图编号一致；净量和损耗可复算；施工性能要求有明确待确认输入。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
