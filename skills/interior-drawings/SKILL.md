# 图纸编排

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

选定平面、模型、材料、定制、灯光与机电条件。

## 执行

1. 建立图号、图名、版本、比例、单位和坐标基准，说明设计阶段。
2. 同源生成尺寸、家具、地材、顶面灯位和机电图，保留CAD模型空间1:1。
3. 选取可解释关键设计的立剖与收口节点，关联材料、柜体和设备编号。
4. 核对总尺寸、分尺寸、开口、标高与表格；导出后检查PDF字体、裁切与CAD单位图层。
5. 对缺少专业计算或实测的图纸使用准确阶段名称，交付仍需补充的信息。

配套通用二维入口为总控`scripts/export_drawings.py`、`export_pdf.py`，用法见[工具用法](../interior-orchestrator/references/tool-guide.md)。总尺寸、分尺寸、画幅和柜体立剖从当前模型推导；铺装线用材料pattern参数，厨卫fixtures缺省时不补画示范设备。柜体详图选择由drawing.joinery_ids指定，未选柜体仍进入完整清单。导出后用校审脚本独立读取文件，不能只看生成成功消息。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

10-drawings.md、PDF图集、SVG与DXF源文件、图纸目录。

图表同源、单位正确、文件可打开；未把设计示范升级为审签施工图。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
