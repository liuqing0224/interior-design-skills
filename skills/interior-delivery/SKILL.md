# 交底与交付配合

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

最终设计版本、图纸、清单、预算、问题台账及当前项目阶段。

## 执行

1. 整理按使用顺序排列的交付包并生成文件哈希，避免旧版和示范故障文件混入最新图纸。
2. 提供交底议程、复尺点、样板要求、隐蔽验收和设备调试清单，按实际状态填写。
3. 现场问题与变更沿用对象和问题编号，记录请求、设计处理、费用及图纸影响。
4. 只在实际发生后填采购、施工和现场验收完成；示范项目以设计交付及现场配合模板结束。
5. 交付README说明入口、版本、文件关系和后续动作，并核对压缩包与原文件一致。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

14-delivery.md、交付索引、交底包、送样/变更/验收模板、文件哈希清单。

交付文件完整可打开，未将现场模板描述成已完成的现场施工或验收。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
