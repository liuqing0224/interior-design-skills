# 概念与材质方向

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

任务书、选定平面、采光与预算。

## 执行

1. 以空间感受、光、触感和维护方式描述概念，避免只给风格标签。
2. 建立主材/辅材/点缀比例及材料编号，明确适用房间和不采用的元素。
3. 检查材料与湿度、清洁、儿童使用及预算相容性。
4. 给出可以用来深化的色板和构件关系，保持与既定开口和尺寸一致。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

04-concept.md、概念板、色板、材料方向表。

每个概念决定有实际空间或材料落点，视觉与平面版本一致。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
