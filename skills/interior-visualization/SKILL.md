# 空间表现

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

已选平面、材料表、家具表、层高和相机目标。

## 执行

1. 先锁定门窗、墙体、家具型号尺寸和材料编号，再建立模型与相机。
2. 优先从同一几何生成平面、轴测与透视；自由生成图必须标为氛围图，并单独核对几何。
3. 检查开口数量、柜体位置、相邻房间关系、材质及尺度，不能用美观替代尺寸核验。
4. 保存模型、相机位置、渲染配置、输入哈希及各视图的实际核验结果。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

05-visualization.md、模型、轴测、代表空间透视、视觉核验清单。

可回溯到模型版本；至少检查总体与代表房间；不声称已经获得未发生的客户视觉批准。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
