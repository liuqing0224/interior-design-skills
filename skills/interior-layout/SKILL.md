# 空间与动线

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

需求矩阵、空间基线、家具尺寸与保留约束。

## 执行

1. 先确定出入口、湿区及结构约束，再布置活动区域和主要家具。
2. 至少比较对当前需求有意义的方案，说明使用人数、活动冲突、储物与成本差异；不为凑数量制造方案。
3. 校核通道、开门、拉椅、柜门、设备操作及检修空间；自定舒适目标必须标为设计目标，不能冒充规范。
4. 把最终家具与通道转成坐标数据，保留尺寸、朝向和活动状态。
5. 向灯位、定制、机电、图纸及效果表现发出平面版本。

使用配套工具时，凹形户型以outline表达真实内轮廓，envelope仅作包围框；把净空间拆为不重叠矩形分区。检查凹口未被误计入面积，柜体front_axis与实际立面方向一致，再运行总控的check与schedules。斜墙、洞中庭和弧形输入需另选几何方法，不强行套入矩形。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

03-layout.md、家具平面、方案比较、净距表。

家具落在所属房间内；主通道连续；候选取舍与需求编号对应。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
