# 定制与木作

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

需求矩阵、测量基线、材料、家电与设备规格。

## 执行

1. 从物品、使用者高度和操作方式确定柜体分区，记录外包尺寸与内部净空。
2. 扣除板厚、背板、踢脚、收口和五金占用，不把立面分格当内部净尺寸。
3. 核对设备开门、散热、电源、给排水、安装顺序及检修空间。
4. 绘制代表柜体平立剖、分格与节点；未取得实际设备图时保留复尺条件。
5. 将柜体长度/投影面积/展开面积分别标明，禁止在报价中混用计量方式。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

08-joinery.md、柜体表、代表立剖面、五金与复尺清单。

关键净尺寸可复算；电器与五金要求有对象；可追踪到材料和预算行。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
