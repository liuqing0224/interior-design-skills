# 工程量与预算

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

面积/长度/数量、材料与设备规格、计量规则、单价来源和费用范围。

## 执行

1. 用数量×单价计算，每行保留对象编号、计量单位、净量、损耗及计价来源。
2. 示范单价明确标为估算参数，不冒充实时市场报价；真实预算核对城市、时间、税费与包工包料范围。
3. 防止硬装、定制、设备、软装与服务重复计价；损耗和预备费只在各自规定层级计取。
4. 汇总总额、预备费、目标预算差额及可替代项，修改输入后重新计算相关结果。
5. 保存前后版本和差额原因，表格中公式与独立计算应一致。

先运行总控schedules生成当前净量，再用`scripts/export_budget.py <项目目录>`调用工作区artifact-tool创建工作簿。运行前按当前Spreadsheets技能的作者要求处理操作标记与依赖；运行时参数见[工具用法](../interior-orchestrator/references/tool-guide.md)。quantity_rule和未联动输入须区分；柜体投影按front_axis正面宽×高计量。工作簿中的净量是该次模型快照，修改project.json后需重新导出，并核对模型和输出哈希。缺价与零价应产生不同结果。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

12-cost.md、工程量与预算CSV/工作簿、变更对比。

算式可追踪、范围完整、无重复计价；总额和预算差额独立复算一致。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
