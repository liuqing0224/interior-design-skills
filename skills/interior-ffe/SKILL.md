# 软装与采购

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

家具平面、概念、材料和预算边界。

## 执行

1. 用家具编号绑定尺寸、数量、材料、颜色、预算单价和房间，不用虚构商品链接。
2. 核对电梯、入口、门洞、转弯、组装方式与安装先后；分体运输与成品使用尺寸分别记录。
3. 整理长周期物料、送样、替代品和到货验收要求。
4. 在未实际采购时只交付询价及采购准备，订单、付款和到货状态必须如实留空。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

11-ffe.md、软装表、采购顺序、物流与验收清单。

数量与平面一致；替代条件明确；报价与估算、采购准备与已采购可区分。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
