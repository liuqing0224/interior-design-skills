# 校审与变更复查

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

当前模型和全部交付、检查范围、设计目标及已核验依据。

## 执行

1. 分别检查几何、编号、跨专业关系、工程量与交付完整性；未做的检查不能写通过。
2. 按ISS编号记录对象、观察事实、输入版本、依据类型、严重度、建议和复核证据。
3. 自动检查适合边界、引用、碰撞和算术；审美、工艺与法规适用性用明确的人工或专业状态。
4. 用同一问题编号关联修改前后版本，复算受影响文件；仅回复不能等同复查关闭。
5. 合成故障用于验证工具时单独标明，不作为真实项目发现或专业检出率。

使用`scripts/verify_2d.py <项目目录>`重新读取SVG、DXF、PDF、CSV和工作簿，核对模型哈希、真实导出尺寸和独立预算算术；`--check-records`针对本套跨户型测试的5个实际阶段，不适用于任意项目的阶段数量要求。案例专用的旧三维检查与通用二维检查分开。新旧户型回归以及变更前后比较都通过后，才说明对应范围已验证。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

13-review.md、问题台账、修改前后检查结果、闭环记录。

关闭项都有新版本证据；未覆盖项仍可见；不宣称自动检查已证明工程合规。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
