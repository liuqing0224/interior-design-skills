# 需求与任务书

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

使用者、空间类型、面积口径、预算范围、交付时间和偏好。

## 执行

1. 将“好看、够用”等需求转成具体活动、人数、物品和优先级，记录冲突与取舍。
2. 说明预算包含硬装、机电、定制、软装、家电、设计服务及预备费中的哪些部分。
3. 为每项关键需求分配REQ编号、验收方式与关联房间；将客户确认与设计者假设分开。
4. 给出需求冻结候选与可调整项，变更后把影响传给平面、机电、采购及成本。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

01-brief.md、需求矩阵、预算边界和待确认事项。

需求都有对应空间或交付物；没有把设定写成真实客户访谈。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
