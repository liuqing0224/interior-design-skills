# 设备与机电接口

先读取[共享项目契约](../interior-orchestrator/references/project-contract.md)，按当前任务选择所需字段，不为缺省项编造事实。

## 输入

建筑设备基线、家具柜体、顶面及拟用设备参数。

## 执行

1. 逐项记录电源、通信、上下水、排风、冷凝水与检修需求，区分意向点位和专业设计。
2. 保留原立管、燃气及结构约束；未核实条件不生成可直接施工的断言。
3. 检查插座被柜体遮挡、设备门碰撞、检修口失效、排水走向与吊顶冲突。
4. 明确回路、导线、保护、负荷、风水管径等专业计算的输入和责任，不从点位图自动推定。
5. 按房间和设备编号输出条件表、协调问题及现场核实项。

具体核对项见[阶段检查表](references/checklist.md)。

## 交付与验收

09-mep.md、设备/点位表、机电条件图、专业接口清单。

每台设备有接口和复核状态；不存在把示意管线作为施工系统图的误导。

## 缺口与恢复

缺少会改变结论的输入时，记录具体缺口、受影响对象及可继续的工作。保留上一版输出，不把待核实项默认为通过。修订后复查受影响文件并记录新哈希。
